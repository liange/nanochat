# nanochat 中文技术文档

本目录是 nanochat 项目的中文技术文档，旨在讲清楚项目的**核心流程、核心类与核心设计**。
文档基于源码分析编写，所有结论均标注了对应的源码位置（格式为 `文件路径:行号`），便于跳转核对。

## 文档结构

| 文档 | 内容 |
|------|------|
| [01-架构总览.md](01-架构总览.md) | 项目定位、设计哲学、目录结构、核心概念（单一复杂度旋钮 `--depth`、精度管理、DDP 等） |
| [02-核心流程.md](02-核心流程.md) | 端到端全流程：tokenization → pretrain → SFT → RL → eval → inference → chat UI |
| [03-核心类与模块.md](03-核心类与模块.md) | 核心库各模块详解：GPT / Optimizer / Engine / Tokenizer / DataLoader / Checkpoint / Eval 等 |
| [04-模型与训练机制.md](04-模型与训练机制.md) | 模型架构细节、Muon+AdamW 混合优化器、精度/dtype、分布式、scaling laws 超参推导 |
| [05-推理与评测.md](05-推理与评测.md) | KV Cache 推理引擎、工具调用状态机、CORE / bpb / ChatCORE 评测体系 |

## 快速导航

- 想了解整体设计哲学与目录布局 → [01-架构总览](01-架构总览.md)
- 想跟着数据走一遍从零到对话的完整链路 → [02-核心流程](02-核心流程.md)
- 想查某个类/模块的职责与接口 → [03-核心类与模块](03-核心类与模块.md)
- 想搞懂模型前向、优化器、分布式、超参是怎么算的 → [04-模型与训练机制](04-模型与训练机制.md)
- 想搞懂推理 KV Cache 与各类评测指标 → [05-推理与评测](05-推理与评测.md)

## 阅读约定

- 所有命令默认从**仓库根目录**运行（nanochat 的入口都是 module）。
- 训练/评估脚本面向 Linux GPU 节点，CPU/MPS 仅作演示用途。
- 文档中的「行号」对应分析时的源码版本，可能随仓库演进略有偏移。
